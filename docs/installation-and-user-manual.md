# 5. คู่มือการติดตั้ง ระบบตรวจสอบงานนักเรียนสำหรับผู้ปกครอง โรงเรียนบ้านแจ้งกู้เรื่อง

### 5.1 ซอฟต์แวร์และเครื่องมือที่จำเป็นสำหรับการติดตั้ง
- **Java JDK 17 ขึ้นไป** (สำหรับคอมไพล์และรันระบบเซิร์ฟเวอร์ Backend Spring Boot 3.2.0)
- **Visual Studio Code** หรือ **IntelliJ IDEA** (เครื่องมือสำหรับพัฒนาและแก้ไขซอร์สโค้ด)
- **MySQL Server 8.0** และ **MySQL Workbench 8.0 CE** (ระบบจัดการฐานข้อมูลเชิงสัมพันธ์)
- **Node.js เวอร์ชัน 18 หรือ 20 ขึ้นไป** พร้อม **npm** (สำหรับรันเว็บแอปพลิเคชัน Frontend Next.js 14)

---

### 5.2 ขั้นตอนการติดตั้งและการตั้งค่าระบบ

#### 1. การติดตั้งและตั้งค่าฐานข้อมูล (Database Setup)
1. เปิดโปรแกรม **MySQL Workbench 8.0 CE** แล้วเชื่อมต่อไปยัง MySQL Server ของเครื่อง
2. เปิดไฟล์สคริปต์ฐานข้อมูล `database/schema.sql`
3. ทำการ Execute สคริปต์เพื่อสร้างฐานข้อมูล `school_system` และตารางทั้งหมด (พร้อมข้อมูลผู้ดูแลระบบตั้งต้น)
4. ตรวจสอบการตั้งค่าพอร์ตและรหัสผ่านในไฟล์ `backend/src/main/resources/application.yml` ให้ตรงกับเครื่อง:
   ```yaml
   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/school_system?useSSL=false&serverTimezone=Asia/Bangkok&characterEncoding=UTF-8&allowPublicKeyRetrieval=true&createDatabaseIfNotExist=true
       username: root
       password: your_password
   ```

#### 2. การติดตั้งและการรันระบบฝั่งเซิร์ฟเวอร์ (Backend Setup)
1. เปิด Terminal ใน Visual Studio Code และเข้าไปยังโฟลเดอร์ Backend:
   ```bash
   cd backend
   ```
2. รันแอปพลิเคชัน Spring Boot ผ่าน Maven Wrapper:
   ```bash
   ./mvnw spring-boot:run
   ```
   *(บนระบบปฏิบัติการ Windows สามารถใช้คำสั่ง `mvnw.cmd spring-boot:run`)*
3. เซิร์ฟเวอร์ Backend จะเริ่มต้นทำงานที่พอร์ต: `http://localhost:8089/api`

#### 3. การติดตั้งและการรันระบบฝั่งหน้าบ้าน (Frontend Setup)
1. เปิด Terminal ใหม่ และเข้าไปยังโฟลเดอร์ Frontend:
   ```bash
   cd frontend
   ```
2. ติดตั้งโมดูลและไลบรารี Dependencies ทั้งหมด:
   ```bash
   npm install
   ```
3. เริ่มต้นรันเซิร์ฟเวอร์สำหรับผู้ใช้งาน (Development Server):
   ```bash
   npm run dev
   ```
4. ระบบหน้าบ้านจะพร้อมใช้งานผ่านเว็บเบราว์เซอร์ที่: `http://localhost:3000`

## 6.1 ส่วนระบบยืนยันตัวตน (Authentication)

### รูปที่ 6.1 การใช้งานของยูสเคส Login
```text
+----------------------------------------------------------------------------------+
|               ระบบตรวจสอบงานนักเรียนสำหรับผู้ปกครอง - โรงเรียนบ้านแจ้งกู้เรื่อง              |
|                                                                                  |
|                        +----------------------------------+                      |
|                        |          เข้าสู่ระบบ (Login)        |                      |
|                        |                                  |                      |
|                        |  ชื่อผู้ใช้งาน (Username)          |                      |
|                        |  [ admin / teacher / parent    ] |                      |
|                        |                                  |                      |
|                        |  รหัสผ่าน (Password)              |                      |
|                        |  [ ••••••••                  👁 ] |                      |
|                        |                                  |                      |
|                        |  [        เข้าสู่ระบบ ->        ]  |                      |
|                        +----------------------------------+                      |
+----------------------------------------------------------------------------------+
```
**รูปที่ 6.1 การใช้งานของยูสเคส Login**

**คำอธิบายภาพใต้รูป:**  
แสดงหน้าจอเข้าสู่ระบบสำหรับผู้ใช้งานทุกระดับ โดยทำการตรวจสอบชื่อผู้ใช้งานและรหัสผ่านเพื่อยืนยันตัวตน พร้อมส่งต่อไปยังหน้าหลักตามบทบาท (Role) ของผู้ใช้

**ขั้นตอนการใช้งาน:**
1. กรอก **ชื่อผู้ใช้งาน (Username)** เป็นภาษาอังกฤษหรือตัวเลขโดยไม่มีช่องว่าง
2. กรอก **รหัสผ่าน (Password)** ความยาวตั้งแต่ 6 ตัวอักษรขึ้นไป
3. คลิกไอคอนดวงตา (👁) หากต้องการเปิดดูรหัสผ่านที่กรอก
4. กดปุ่ม **"เข้าสู่ระบบ"** ระบบจะตรวจสอบความถูกต้อง หากถูกต้องจะบันทึก JWT Token และเปลี่ยนหน้าไปตามสิทธิ์ผู้ใช้:
   - ผู้ดูแลระบบ (Admin) -> หน้าแดชบอร์ดภาพรวมระบบ
   - ครูผู้สอน / ครูประจำชั้น (Teacher) -> หน้าชั้นเรียนประจำชั้น / ตารางสอน
   - ผู้ปกครอง (Parent) -> หน้าแดชบอร์ดติดตามบุตรหลาน
